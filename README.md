# SmartWasteAI

## Cloud-Based Smart Waste Classification and Recycling Management System

SmartWasteAI is a deep learning and cloud computing project that automatically classifies waste from images and provides appropriate recycling or disposal recommendations.

## Project Objectives

- Develop a deep learning model for waste image classification.
- Compare a baseline CNN with transfer learning using MobileNetV2.
- Deploy the trained model as a cloud-based inference service.
- Use cloud storage for waste images.
- Store prediction history in a cloud database.
- Implement event-driven and asynchronous cloud processing.
- Monitor the deployed application using cloud monitoring services.
